# cafe-static

基礎專題「轉角咖啡一頁式網站」（`specs/CAFE-SPEC.md` §7）的**靜態版面**，Angular 課 ch08–11（HTML / CSS）的專題練習參考解答。

- 直接用瀏覽器打開 `index.html` 就能看（不需要安裝任何東西）。
- `style.css` 依章節分成三段：ch09 文字與 Box Model、ch10 Flex 與 `:hover`、ch11 背景圖與 position。
- 菜單先寫死三張卡片，訂位表單還不能送出；到 Angular ch58（`projects/cafe-web`）才拆成元件、接上 API。class 名稱和區塊順序跟 cafe-web 一致。
